# ภาพรวม

## วิสัยทัศน์

ชุดมินิเกม "ฝึกวิชา" แนวจอมยุทธสำหรับเซิร์ฟโรลเพล ผู้เล่นเดินไปหาหญ้าวิญญาณ หุ่นไม้ หรือแท่นฝึกที่ admin วางไว้ คลิกขวาเพื่อเริ่ม แล้วเล่นด้วยปุ่มพื้นฐาน **เห็นแล้วเข้าใจทันที แต่ยังยากและต้องใช้ฝีมือ**

คนภายนอกเห็นแค่ผู้เล่นคนหนึ่งกำลังก้มถอนหญ้าอย่างตั้งใจ ส่วนคนเล่นเห็นหญ้าเรืองแสงเต้นเป็นจังหวะอยู่ตรงหน้า

## หลักการออกแบบ (ห้ามละเมิดโดยไม่บันทึกใน [`decisions.md`](decisions.md))

0. **Immersion มาก่อน:** ไม่ดูเป็นเกมในสายตาคนอื่น วัตถุเป็นบล็อกธรรมดาในโลก ไม่มีแถบ HP ไม่มีตัวเลข cue แสดงบนตัววัตถุและเห็นเฉพาะคนเล่น ดู [`design/core-mechanics.md`](design/core-mechanics.md) หัวข้อ 0 และ 9
1. **เรียบง่ายก่อน:** อะไรที่วุ่นวายให้ตัดทิ้ง ไม่มีมานา, ไม่มีเวลาเกิดใหม่, ไม่มีเกจซ้อนกันหลายชั้น
2. **admin เป็นคนจัดสรร:** ทุกอย่างวางด้วยมือเหมือนบล็อกทั่วไป (หรือ `/setblock`) และปรับค่าผ่าน NBT หญ้าใช้ได้ครั้งเดียว ถอนแล้วหายไป ถ้าทุบตรงๆ จะพังและโดนลงโทษ
3. **ปุ่มมีแค่ LMB, RMB, Space และ WASD:** ไม่มีการลากเมาส์ ไม่มี GUI แยก
4. **ทุกเกมใช้โครงเดียว คือ HP + Pattern:** ดู [`design/core-mechanics.md`](design/core-mechanics.md)
5. **บทลงโทษใช้ของ vanilla:** effect, damage, ไฟ, แข็ง, ระเบิดที่ไม่ทำลายบล็อก, knockback
6. **ตรวจผลได้:** ทุกผลลัพธ์ลง log และ scoreboard เพื่อให้ admin เอาไปใช้ในโรลเพลต่อได้
7. **รันเดี่ยวได้:** bhfx และ BHSpells เป็น soft dependency mod ต้องเล่นได้แม้ไม่มีสองตัวนี้

## คำศัพท์

| คำ | ความหมาย |
| :--- | :--- |
| **Training block** | บล็อกที่ admin วาง (มี block entity เก็บค่า) ผู้เล่นคลิกขวาเพื่อเริ่มเล่น |
| **Herb** | training block แบบใช้ครั้งเดียว (หญ้าวิญญาณ) จบเกมแล้วหายไป |
| **Station** (แท่นฝึก) | training block แบบถาวร (หุ่นไม้, เสื่อฟังลม, แท่นดับเทียน) จบเกมแล้วรีเซ็ต เล่นซ้ำได้ |
| **Combatant** | (backlog) entity ที่ตีได้และโจมตีกลับ มีพลังชีวิตจริง เป็นระบบแยกจาก minigame engine |
| **Session** | การเล่นหนึ่งรอบของผู้เล่นหนึ่งคนกับบล็อกหนึ่งอัน |
| **Diegetic cue** | cue ที่แสดงบนวัตถุในโลก (แสง, สี, ประกาย) แทน UI บนจอ เห็นเฉพาะคนเล่น |
| **Input profile** | การตั้งค่าต่อเกมว่าดักปุ่มไหน, ล็อกกล้องไหม, แสดง crosshair ไหม, ส่ง input แบบไหน |
| **Cue channel** | cue แสดงที่ไหน: บนบล็อก (`BLOCK`), ลูกศรในโลก (`WORLD_ARROW`), เป้ารอบตัว (`WORLD_TARGET`), เสียงระบุทิศ (`SPATIAL_AUDIO`) |
| **Target set** | รายการตำแหน่งเป้าในโลกที่หาไว้ตอนเริ่ม session (เช่น เทียนรอบแท่น) |
| **Cue** | คำสั่งที่ pattern ส่งให้ผู้เล่น เช่น "กด LMB ภายใน 0.5 วินาที" |
| **Pattern** | ตัวสร้างลำดับ cue ของแต่ละเกม (logic ฝั่ง server) |
| **Phase** | ช่วงของ pattern ที่เปลี่ยนตาม HP ที่เหลือ เช่น HP ต่ำกว่าครึ่ง → เร็วขึ้น |
| **Gauge** | เกจเสริมนอกจาก HP เช่น เกจความร้อน, เกจชักเย่อ |
| **Mistake** | การพลาดหนึ่งครั้ง พลาดครบ `MaxMistakes` = แพ้ |
| **Outcome** | ผลจบเกม: `PERFECT` / `SUCCESS` / `FAIL` / `ABORTED` |
