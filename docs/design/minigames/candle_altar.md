# แท่นดับเทียนร้อยเล่ม (`candle_altar`)

**สถานะ:** 📝 ออกแบบ (ย้ายจาก backlog เข้าแผนหลัก 2026-10-19)

## แนวคิด
ฝึกความเร็วของสายตาและความแม่นของดรรชนี เทียนรอบลานฝึกจะลุกขึ้นทีละเล่ม ต้องหันไปดีดนิ้วส่งปราณดับให้ทันก่อนเทียนมอดไปเอง

## รูปแบบ
- **ประเภท:** Station
- **หน้าตาบล็อก:** แท่นบูชาหรือกระถางธูปหิน ผู้เล่นคลิกขวาที่แท่นเพื่อเริ่ม
- **เป้า:** **เทียนจริงของ vanilla ที่ admin วางไว้รอบแท่น** (สีไหนก็ได้ กี่เล่มต่อบล็อกก็ได้)
- **ปุ่ม:** `LMB` (ดีดนิ้ว)
- **Input profile:** `camera=FREE` (หมุนได้ เดินไม่ได้), `crosshair=true`, `aimPayload=true`, `sendIdlePresses=false`
- **Channel:** `WORLD_TARGET`
- **ค่าเริ่มต้น:** `MaxHP` = 20 (เทียนที่ต้องดับ), `MaxMistakes` = 5, `TimeLimit` = ไม่มี
- **NBT เพิ่ม:** `Radius` (ค่าเริ่มต้น 8, สูงสุด 12) ระยะที่สแกนหาเทียน
- **ท่าทางที่คนภายนอกเห็น:** `QI_FLICK` (ยืนตั้งท่า ยกมือชี้ ดีดนิ้วเป็นระยะแบบ loop)
- **คำใบ้ตอนเริ่ม:** "เปลวไฟจะลุกขึ้นเพียงชั่วครู่… ดับมันด้วยปลายนิ้ว"

## Target set (หาเป้าตอนเริ่ม)
1. สแกนบล็อกเทียน (`CandleBlock`) ที่ **ยังไม่ติดไฟ** ในรัศมี `Radius` รอบแท่น (เทียนที่ติดไฟอยู่แล้วถือเป็นของตกแต่ง ไม่นับ)
2. ตัดเทียนที่มองไม่เห็นจากตำแหน่งตาของผู้เล่นออก (raycast ฝั่ง server หนึ่งครั้งต่อเทียน)
3. เก็บได้สูงสุด 32 ตำแหน่ง ถ้าได้ไม่ถึง 3 เล่ม ไม่เริ่ม session และขึ้นข้อความในเรื่อง ("เทียนรอบแท่นน้อยเกินไป") พร้อมเขียน log ให้ admin
4. ส่งรายการตำแหน่งใน `S2CSessionStart` ครั้งเดียว

สแกนครั้งเดียวต่อ session (รัศมี 8 = ตรวจประมาณ 5,000 บล็อก ใช้เวลาไม่ถึง 1ms)

## Pattern
แต่ละ cue คือเทียนหนึ่งเล่มลุกขึ้น = `AIM` ที่เป้า index นั้น
- **telegraph** (ช่วง `leadTicks`): ไส้เทียนเริ่มมีประกายวาบๆ
- **กรอบเวลา:** เปลวไฟลุกเต็ม ถ้ายังไม่ดับเมื่อหมดกรอบ เปลวจะมอดไปเอง = mistake

| Phase | เงื่อนไข | เทียนที่ลุกพร้อมกัน | กรอบเวลาต่อเล่ม (Difficulty 1 / 2 / 3) | อื่นๆ |
| :--- | :--- | :--- | :--- | :--- |
| 1 | HP > 60% | 1 | 30 / 24 / 20 tick | เลือกเทียนใกล้ทิศที่มองอยู่ก่อน |
| 2 | HP ≤ 60% | สูงสุด 2 | 24 / 20 / 16 tick | สุ่มทั่วลาน รวมด้านหลัง, มี **เปลวไฟวิญญาณสีฟ้า** = `FEINT` (ห้ามดับ) |
| 3 | HP ≤ 25% | สูงสุด 3 | 20 / 16 / 12 tick | เทียนลุกถี่ขึ้น |

**การยิง:**
- ดีดนิ้วแล้วต้องพัก 6 tick ก่อนยิงครั้งต่อไป (กันการรัวคลิกกวาดไปทั่ว)
- ยิงไม่โดนเป้า: ไม่นับเป็น mistake แต่เสียเวลาพัก client ไม่ส่ง packet (ตาม `sendIdlePresses=false`) แค่เล่นเสียงลมวืดในเครื่องตัวเอง
- **client ส่ง input เฉพาะตอนที่เส้นเล็งของตัวเองโดนเปลวไฟ** (จริงหรือวิญญาณ) พร้อม yaw/pitch ตอนกด

**ตรวจผลฝั่ง server:**
1. yaw/pitch ที่ส่งมาต้องใกล้กับทิศที่ server รู้ของผู้เล่น (คลาดได้ไม่เกิน ~15° เผื่อ ping)
2. เส้นจากตาผู้เล่นตามทิศที่ส่งมาต้องผ่านกล่องรอบเปลวไฟ (ขยายขนาดให้ยิงง่ายขึ้นเล็กน้อย) และไม่มีบล็อกบัง
3. เทียนเล่มนั้นต้องลุกอยู่ในกรอบเวลา (รวม `pingGrace`)

## บทลงโทษ
- **เทียนมอดไปเอง:** mistake อย่างเดียว ไม่มีบทลงโทษ
- **ดับเปลวไฟวิญญาณ:** mistake + ไฟลวก (`fire` 1 วินาที)
- **FAIL:** `fire` 2 วินาที + Slowness I 3 วินาที (ปราณตีกลับ)
- **ทุบตรงๆ:** แท่นไม่พัง ไม่มีบทลงโทษ (เป็นแค่แท่นหิน) ส่วนเทียนของ admin ทุบได้ตามปกติ (เป็นบล็อก vanilla ให้ admin จัดการเอง)

## การแสดงผล
- **คนเล่นเห็น:**
  - เทียนจริงในโลกติดไฟ **เฉพาะบนจอคนเล่น** วาดเป็นเปลวไฟปลอม (particle `SMALL_FLAME` + แสงเรืองแบบ billboard) **ห้ามเปลี่ยน blockstate `lit` ของเทียนจริง** เพราะจะทำให้ทุกคนเห็น
  - ดับสำเร็จ: เปลวดับพร้อมควันขาวลอยขึ้น
  - เปลวไฟวิญญาณ: สีฟ้าซีด สั่นไหวผิดธรรมชาติ
  - crosshair แบบจุดพู่กันเล็กๆ แทน crosshair ของ vanilla
- **HUD:** ไม่มีอย่างอื่น
- **เสียง (เฉพาะคนเล่น):** เสียงไฟลุกพรึบจากทิศของเทียน (ช่วยหาเทียนที่อยู่ด้านหลัง), เสียงไฟดับฟู่, เสียงลมวืดตอนยิงพลาด
- **คนภายนอกเห็น:** ผู้เล่นยืนหันไปมาและดีดนิ้วใส่เทียนที่ดับอยู่ ตอนแพ้เห็นผู้เล่นมีไฟลุกที่ตัว
- **bhfx / fallback:** ไม่จำเป็น

## คำถามที่ยังเปิดอยู่
- ถ้าลานเทียนกว้างมาก ผู้เล่นอาจหาเทียนด้านหลังไม่เจอ เสียงจากทิศของเทียนน่าจะพอ ต้องลองเล่นจริงก่อน
- มีเทียนหลายเล่มในบล็อกเดียว (1–4 เล่ม) นับเป็นเป้าเดียว (ข้อเสนอ: นับเป็นเป้าเดียว)
