## แกนสำหรับสร้าง variant ของหญ้า

หญ้าใหม่ส่วนใหญ่ไม่ต้องเขียน core ใหม่ แค่เลือกค่าจากแต่ละแกนแล้วผสมกัน ถ้าแตะแกนเดียวก็มักจะได้หญ้าที่รู้สึกต่างแล้ว

| แกน | ตัวเลือก | ตัวอย่าง |
| :--- | :--- | :--- |
| ปุ่ม | `LMB` / `LMB`+`RMB` / ค้าง + `SPACE` | ชีพจร / หยินหยาง / อสุนีบาต |
| ชนิด cue | `TAP` / `HOLD` / `FEINT` / ผสม | หยินหยางใช้ `FEINT` |
| จังหวะ | สม่ำเสมอ / สุ่ม / เร่งขึ้น / จังหวะคู่ (double beat) | ชีพจร phase 2 |
| gauge | ไม่มี / หนึ่งอัน / สองอัน | หญ้าไฟ |
| จำนวนคน | 1 / **2 (แบ่ง role)** | หญ้าเกี่ยวรากคู่ |
| เงื่อนไขในโลก | ไม่มี / กลางคืนเท่านั้น / ฝนตก / ต้องอยู่ใกล้น้ำ | (ไอเดีย) เช็กแค่ตอนเริ่ม ไม่กิน CPU |
| บทลงโทษ | Poison / ไฟ / `burst` / `strikeVisual` / Slowness | ตามธีมของหญ้า |

ข้อควรระวัง: variant ที่ต่างกันแค่ตัวเลขไม่ควรเป็นบล็อกใหม่ ให้ใช้ NBT `Difficulty` แทน บล็อกใหม่ควรมีอย่างน้อยหนึ่งแกนที่เปลี่ยนวิธีคิดของคนเล่น
