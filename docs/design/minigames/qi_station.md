# แท่นประชันปราณ (`qi_station`)

**สถานะ:** 🔨 เขียนโค้ดแล้ว 2026-11-02 แบบ **PvP อย่างเดียว** (D58) build ผ่าน ปรับให้ยากขึ้น (คลื่นหลอก, กันต้องปล่อยมือ, D59) เพิ่มการดึงกลับด้วย `Shift` 2026-11-05 (D76) unit test 22 ข้อผ่าน **ยังไม่ได้ลองในเกม** (ดู [`testing.md`](../../testing.md))
(เดิมเป็นแบบเล่นคนเดียวสู้ลูกแก้ว อยู่ใน backlog ตั้งแต่ 2026-10-19 (D21) ผู้ใช้เลือกทำเป็น PvP อย่างเดียวเมื่อ 2026-11-02 จึงตัดลูกแก้วที่เล่นเองออก เหลือไว้แค่ตอนลูกแก้วคลั่ง)

## แนวคิด
แท่นหินที่มีลูกแก้วปราณลอยอยู่ ผู้เล่นสองคนยืนคนละฝั่ง ยื่นฝ่ามือดันลูกแก้วเข้าหาอีกฝ่าย ลูกแก้วไปถึงตัวใครก่อน คนนั้นแพ้
ไม่ใช่แค่ค้างปุ่มแข่งกัน ต้องเลือกจังหวะส่งคลื่นปราณ อ่านให้ออกว่าอีกฝ่ายกำลังรวมพลังมาเมื่อไร และเลือกระหว่างดันกับดึง (ยืมแรง) เหมือนเป่ายิ้งฉุบ: ดันชนะคนที่ไม่ทำอะไร ดึงที่ติดมือแล้วชนะคนดัน ส่วนคนดึงเฉยๆ เสียพื้นที่เอง

## รูปแบบ
- **ประเภท:** Station ไม่พัง ไม่ต้องรีเซ็ต (`BruteForce=KEEP`)
- **จำนวนคน:** 2 คน (`requiredPlayers=2`) คนแรกที่คลิกรอคู่ (`WAITING`) ตามกฎเกมหลายคน (D31, D32)
- **ตำแหน่งยืน:** ห่างกลางแท่น 1.4 บล็อก คนแรกถูกย้ายไปฝั่งที่ใกล้ที่สุด**ทันทีที่คลิก** (ฝั่งนี้ตายตัว) คนที่สองถูกย้ายไป**ฝั่งตรงข้ามเสมอ** ไม่ว่าจะคลิกจากฝั่งไหน ถ้าฝั่งตรงข้ามยืนไม่ได้ จะร่วมไม่ได้และขึ้นข้อความ "ฝั่งตรงข้ามคู่ประชันไม่มีที่ให้ยืน" (`facesOff`, D58, D62)
- **หน้าตาบล็อก:** แท่นหินสลัก (placeholder ใช้ texture ของ vanilla) ลูกแก้ววาดบนเครื่องคนเล่นเท่านั้น
- **ปุ่ม (ทั้งสอง role เหมือนกัน):** `LMB` ค้าง = ดันปราณ, `Shift` ค้าง = ดึงกลับ (D76), `RMB` = ส่งคลื่นปราณ, `Shift` + `RMB` = คลื่นหลอก, `SPACE` = สะท้อน `sendIdlePresses=true` ปุ่มค้าง: `LMB`, `SNEAK`
- **ค่าเริ่มต้น:** ไม่ใช้ HP, `MaxMistakes` = 1000 (mistake นับรวมสองคน จึงห้ามให้มันจบเกม ลูกแก้วเป็นตัวตัดสิน)
- **Gauge:** `tug` (index 0, `FLAG_TUG`) คือตำแหน่งลูกแก้ว 0 = ชิดตัว role 0, 1 = ชิดตัว role 1 เริ่มที่ 0.5 ถึง 1 → role 0 ชนะ ถึง 0 → role 1 ชนะ
- **ท่าทางที่คนภายนอกเห็น:** `PALM_PUSH`

## Pattern

| การกระทำ | ผล |
| :--- | :--- |
| ค้าง `LMB` | ลูกแก้วเลื่อนเข้าหาอีกฝ่าย 1/200 ต่อ tick (จากกลางถึงตัวประมาณ 5 วินาที) ค้างทั้งคู่ = หักล้างกัน ไม่ค้างทั้งคู่ = นิ่ง |
| ค้าง `Shift` (ดึงกลับ, D76) | ลูกแก้วเลื่อนเข้าหาตัวเอง 0.7/200 ต่อ tick (เสียพื้นที่เอง) ค้างครบ **10 tick** แล้วการดึง "ติดมือ" ถ้าตอนนั้นอีกฝ่ายดันอยู่ (หรือเริ่มดันทีหลัง) แรงดันย้อนกลับ: ลูกแก้วเลื่อนเข้าหา**คนดัน** 2/200 ต่อ tick แทน ระหว่างยังไม่ติดมือ แรงดันกับแรงดึงรวมกันเข้าหาคนดึง 1.7/200 ต่อ tick (ราคาของการเสี่ยง) คนดันเห็นท่าดึงแล้วปล่อยมือทันได้ ดึงทั้งคู่ = หักล้างกัน ค้าง `LMB` กับ `Shift` พร้อมกัน = นับเป็นดึง ปล่อย `Shift` แล้วกดใหม่ต้องรอติดมือใหม่ |
| `RMB` (ส่งคลื่น) | ลูกแก้วรวมพลังไปทางอีกฝ่าย 18 / 16 / 13 tick (Difficulty 1 / 2 / 3) แล้วระเบิด ส่งได้อีกครั้งหลังคลื่นนั้นตัดสินแล้ว + 30 tick และส่งไม่ได้ถ้ามีคลื่นที่ยังไม่ตัดสินมุ่งไปหาอีกฝ่ายอยู่ |
| `SPACE` ในกรอบเวลาระเบิด (10 / 8 / 6 tick) | **สะท้อนกลับ:** ลูกแก้วเลื่อนเข้าหาคนส่ง 0.1 |
| ไม่กด หรือกด `SPACE` ตอนลูกแก้วยังรวมพลัง (ก่อนกรอบเปิด) | **โดนเต็มๆ:** ลูกแก้วเลื่อนเข้าหาตัวเอง 0.25 + บทลงโทษเล็ก + นับ mistake กดอีกครั้งในกรอบก็ไม่ช่วยแล้ว |
| `Shift` + `RMB` (คลื่นหลอก, D59) | ลูกแก้วรวมพลังเหมือนคลื่นจริงทุกอย่าง (เสียงเดียวกัน) แต่ 6 tick ก่อนกรอบเปิดจะกลายเป็นสีม่วง ใช้คูลดาวน์เดียวกับคลื่นจริง อีกฝ่ายกด `SPACE` ใส่ = ลูกแก้วเลื่อนเข้าหาเขา **0.15** (เดิม 0.1) ไม่กด = ไม่มีอะไร คลิกขวาระหว่างค้าง `Shift` ดึงอยู่จึงเป็นคลื่นหลอกเสมอ (ต้องปล่อย `Shift` ก่อนถึงจะส่งคลื่นจริงได้) |
| `SPACE` ตอนไม่มีอะไรพุ่งมา | **รับลม:** ลูกแก้วเลื่อนเข้าหาตัวเอง 0.05 (กันกดรัว) |
| `SPACE` ระหว่างค้าง `LMB` หรือ `Shift` หรือภายใน 4 tick หลังปล่อย (D59, D76) | **ไม่มีผล** (ไม่สะท้อน ไม่นับรับลม) ต้องเลือกว่าจะดัน/ดึงต่อหรือปล่อยมือตั้งรับ ปล่อยแล้วก็เสียแรงช่วงนั้น |

กรอบเวลาขยายตาม ping ของคนรับ (`pingGrace`) ตามกฎ `BeatTrack` คลื่นส่งให้ client ทันทีตอนกด `RMB` ระยะรวมพลัง 13–18 tick จึงพอสำหรับ ping 250ms

### ลูกแก้วคลั่ง (กันเสมอ)
หลังเริ่ม 60 วินาทีถ้ายังไม่จบ ขึ้นข้อความตัวใหญ่ "ลูกแก้วเริ่มคลั่ง" แล้วลูกแก้วระเบิดเองทุก 40–80 tick ใส่ฝั่งที่สุ่ม (ข้ามฝั่งที่มีคลื่นรอตัดสินอยู่)
- 25% เป็น **รวมพลังหลอก** (`FEINT`, เป็นสีม่วง 6 tick ก่อนกรอบเปิดเหมือนคลื่นหลอกของผู้เล่น): กด `SPACE` = ลูกแก้วเลื่อนเข้าหาตัวเอง 0.15
- ระเบิดจริงที่รับไม่ได้ = เลื่อนเข้าหาตัวเอง 0.15 + บทลงโทษเล็ก, สะท้อนได้ = ลูกแก้วสลายไป ไม่เลื่อน
- กรอบเวลาของทุกคลื่น (รวมของผู้เล่น) แคบลง 1 tick ทุก 20 วินาที ต่ำสุด 4 tick ดวลจึงจบเสมอ

## บทลงโทษ
- **รับคลื่นไม่ได้:** knockback 0.3 (นอกจากลูกแก้วเลื่อน) คนภายนอกเห็นท่าโดนกระแทก
- **แพ้ (ลูกแก้วถึงตัว):** `FAIL` knockback 1.0 + Weakness 10 วินาที
- **ชนะ:** `PERFECT` ถ้าตัวเองไม่พลาดเลย ไม่งั้น `SUCCESS` drop loot เฉพาะถ้า admin ตั้ง loot table ใน NBT
- **ออกกลางคัน:** ตามกฎเกมหลายคน (D32) คนออกได้ `FAIL` + บทลงโทษใหญ่ อีกคนได้ `ABORTED` ไม่ได้ชัยชนะ (กันใช้บัญชีสำรองออกให้ชนะ)
- **ทุบตรงๆ:** แท่นไม่พัง พลังตีกลับ: knockback 0.6 + Weakness 5 วินาที

## การแสดงผล
- **คนเล่นเห็นบนตัววัตถุ:** (placeholder ตอนนี้เป็นกล่องเรืองแสง)
  - ลูกแก้วลอยอยู่บนเส้นระหว่างแท่นกับตัวเรา ไกลใกล้ตาม `tug` สีฟ้าซีดตอนอยู่กลาง แดงเมื่อเข้าใกล้เรา ทองเมื่อเข้าใกล้อีกฝ่าย
  - คลื่นที่พุ่งมาหาเรา: ลูกแก้วหดตัวและสว่างขึ้นตลอดช่วงรวมพลัง สว่างเต็มตอนกรอบเปิด รวมพลังหลอกดูเหมือนกันจนถึง 6 tick ก่อนกรอบเปิดแล้วจึงเป็นสีม่วง
  - คลื่นที่เราส่งไป: ลูกแก้วสว่างจางๆ
- **HUD:** ไม่มี (มีแค่ข้อความตัวใหญ่ตอนลูกแก้วคลั่ง)
- **เสียง (เฉพาะคนรับ):** เสียงฮึมตอนลูกแก้วเริ่มรวมพลัง (ตอนที่ cue มาถึง) หลอกกับจริงเสียงเดียวกัน
- **ทุกคนในระยะเห็น (D60, คนเล่นด้วย):** ลูกแก้วตำแหน่งเดียวกับที่คนเล่นเห็น (คนดูเห็นสีฟ้าซีดที่อุ่นเป็นทองเมื่อเข้าใกล้คนใดคนหนึ่ง และสว่างขึ้นตอนรวมพลัง ไม่ว่าจริงหรือหลอก) และ particle placeholder:
  - ค้าง `LMB`: สายปราณ (`END_ROD`) ไหลจากฝ่ามือเข้าลูกแก้ว ดันทั้งคู่: ประกายไฟฟ้า (`ELECTRIC_SPARK`) ตรงลูกแก้ว
  - **ค้าง `Shift` (D76):** เริ่มดึง = ปราณสีฟ้า (`SOUL_FIRE_FLAME`) ฉีกจากลูกแก้วเข้าฝ่ามือ + เสียงหอกตรีศูลย้อนกลับ (`TRIDENT_RETURN`) ระหว่างดึง = ปราณสีฟ้าไหลจากลูกแก้วเข้าฝ่ามือ (ทุก 2 tick) แขนดึงกลับเข้าหาอกสั่นเล็กน้อย ติดมือ = วงประกายฟ้ารอบฝ่ามือ + เสียง `RESPAWN_ANCHOR_CHARGE` แล้วสายปราณหนาขึ้นและมีวงฟ้าหมุนรอบมือตลอด ย้อนแรงดัน = ฟันวาบ (`SWEEP_ATTACK`) ตรงลูกแก้ว ปราณฟ้าฟาดเข้าอกคนดัน + `CRIT` + เสียงฟัน (`PLAYER_ATTACK_SWEEP`) และ `TRIDENT_RIPTIDE_1` ระหว่างย้อนแรงมีปราณขาวพุ่งจากลูกแก้วเข้าอกคนดัน ทุกอย่างทำบน client จากปุ่มค้างที่ส่งอยู่แล้ว + เหตุการณ์ `GRIP`/`YIELD` (ครั้งเดียวต่อการดึง, `YIELD` ไม่เกิน 1 ครั้งต่อ 10 tick ต่อคน)
  - ส่งคลื่น (จริงหรือหลอกเหมือนกัน): ปราณพุ่งจากฝ่ามือเข้าลูกแก้ว แล้วอักขระ (`ENCHANT`) ไหลเข้าลูกแก้วตลอดช่วงรวมพลัง
  - **คลื่นของเราเอง (D65, เห็นบนจอเราเท่านั้น):** คลื่นจริงสีทอง คลื่นหลอกสีม่วง (ดูจากว่ากด `Shift` อยู่ไหมตอนคลิกขวา) ทั้งปราณที่พุ่งจากฝ่ามือและวงประกายที่หดเข้าลูกแก้ว (แทนอักขระ) จะได้ไม่สับสนกับคลื่นที่อีกฝ่ายส่งมา (สีขาว + อักขระ)
  - สะท้อนสำเร็จ: แสงวาบ (`FLASH`) แล้วปราณพุ่งกลับไปหาคนส่ง / โดน: ปราณพุ่งเข้าอก + ระเบิดเล็ก / กดใส่คลื่นหลอก: ควันม่วงพุ่งเข้าหาคนกด / คลื่นหลอกไม่มีใครกด: ควันม่วงสลาย / รับลม: ฝุ่นตรงฝ่ามือ
  - particle เกิดเฉพาะคนที่อยู่ใน 24 บล็อก (ผลถูก/พลาดแบบหญ้าไม่ใช้กับเกมนี้แล้ว)
- **คนภายนอกเห็น:** สองคนยื่นแขนทั้งสองข้างตรงไปที่ลูกแก้ว (`PALM_PUSH` แบบ vanilla: แขนตามทิศหัวที่กล้องล็อกไว้ ดันเข้าออกช้าๆ ตอนค้าง `Shift` แขนดึงกลับเข้าหาอกและสั่น) ตอนส่งคลื่นเห็นแขนสองข้างดันพุ่งไปข้างหน้า (`PUNCH_FINISH`) ตอนโดนเห็นท่าโดนกระแทก
- **bhfx / fallback:** (P6) screen pulse ตอนระเบิดใส่เรา, flash ตอนสะท้อนสำเร็จ fallback particle `END_ROD`

## ยังไม่ทำ
- โมเดลแท่นและลูกแก้วจริง, particle และเสียงของ bhfx แทนของ vanilla, เสียงตอนสะท้อนสำเร็จ (P6)
- ท่า `PALM_PUSH` ของ playerAnimator (P2b/P6)
- ข้อความตอนทุบตรงๆ ยังใช้ของ station ทั่วไป ("ไม้ไม่ขยับ…") ซึ่งไม่เข้ากับแท่นหิน
