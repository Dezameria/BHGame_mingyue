# แท่นประชันปราณ (`qi_station`)

**สถานะ:** 💤 **Backlog** (ย้ายออกจากแผนหลัก 2026-10-19, D21) เก็บสเปกไว้สำหรับทำทีหลังหรือทำพร้อมโหมด PvP
(เดิมชื่อ `qi_master` "อาจารย์ประชันปราณ" เปลี่ยนเป็นแท่นฝึกตาม D16 เมื่อ 2026-10-19 และสเปกนี้ยังใช้ `burst`/`strikeVisual` ตามกฎใหม่ไม่ได้ปรับ ต้องทบทวนก่อนทำ)

## แนวคิด
แท่นหินที่มีลูกแก้วปราณลอยอยู่ ผู้เล่นวางฝ่ามือส่งปราณเข้าไปประชันกับพลังที่สะสมในลูกแก้ว ต้องดูจังหวะรุกและรับ ไม่ใช่แค่รัวปุ่ม
ในโรลเพล admin หรือผู้เล่นที่เล่นเป็นอาจารย์ยืนอยู่อีกฝั่งของแท่นได้ เพื่อให้ดูเหมือนกำลังประชันกับอาจารย์

## รูปแบบ
- **ประเภท:** Station
- **หน้าตาบล็อก:** แท่นหินสลัก มีลูกแก้วใสลอยอยู่ด้านบน
- **ปุ่ม:** `LMB` ค้าง (ดันปราณ) + `SPACE` (เคาน์เตอร์)
- **ค่าเริ่มต้น:** ไม่ใช้ HP และไม่ใช้ mistake
- **Gauge:** `tug` (−1 = ฝั่งผู้เล่น, +1 = ฝั่งลูกแก้ว) เริ่มที่ 0 ถึง +1 = ชนะ ถึง −1 = แพ้
- **ท่าทางที่คนภายนอกเห็น:** `PALM_PUSH`

## Pattern
ลูกแก้ววนอยู่ระหว่างสามสถานะ:

| สถานะ | ลูกแก้วทำ | ผู้เล่นควรทำ |
| :--- | :--- | :--- |
| `GUARD` | หมุนช้าๆ ค่อยๆ ดันพลังกลับมาทางผู้เล่น | ค้าง `LMB` เพื่อดันกลับ |
| `CHARGE` | หดตัวและสว่างขึ้น 0.6–1.0 วินาที | เตรียมตัว (ค้าง `LMB` ต่อได้) |
| `BURST` | ระเบิดพลังสวน | `TAP SPACE` ภายในกรอบเวลา = เคาน์เตอร์ `tug` +0.15 / ถ้าพลาด `tug` −0.25 |

| Phase | เงื่อนไข | กรอบเวลาของ BURST (Difficulty 1 / 2 / 3) | อื่นๆ |
| :--- | :--- | :--- | :--- |
| 1 | `tug` < 0.5 | 10 / 8 / 6 tick | CHARGE ทุก 3–5 วินาที |
| 2 | `tug` ≥ 0.5 | 8 / 7 / 5 tick | CHARGE ถี่ขึ้น และมี **CHARGE หลอก** (สว่างแล้วคลายตัว = `FEINT` กด `SPACE` แล้ว `tug` −0.1) |

## บทลงโทษ
- **พลาดเคาน์เตอร์:** knockback เล็กน้อย (นอกจาก `tug` ลด)
- **FAIL:** knockback แรง + Weakness 10 วินาที
- **ทุบตรงๆ:** แท่นไม่พัง (`BruteForce=KEEP`) และพลังตีกลับ: knockback + Weakness 5 วินาที

## การแสดงผล
- **คนเล่นเห็นบนตัววัตถุ:**
  - `tug`: ลูกแก้วลอยเลื่อนเข้าใกล้ผู้เล่นหรือออกห่าง และเปลี่ยนสีตามฝั่งที่ได้เปรียบ (ไม่มีเกจบนจอ)
  - `CHARGE`: ลูกแก้วหดตัวและสว่างขึ้น, `BURST`: วงคลื่นกระจายออก
  - มีสายปราณเชื่อมจากฝ่ามือผู้เล่นไปถึงลูกแก้วตอนค้าง `LMB`
- **HUD:** ไม่มี
- **เสียง (เฉพาะคนเล่น):** เสียงฮึมตอน CHARGE, เสียงระเบิดตอน BURST, เสียงกังวานตอนเคาน์เตอร์สำเร็จ
- **คนภายนอกเห็น:** ผู้เล่นยื่นฝ่ามือใส่ลูกแก้วที่ลอยนิ่ง, ตอนพลาดเห็นผู้เล่นกระเด็นถอยหลัง
- **bhfx / fallback:** screen pulse + zoom blur ตอน BURST, flash ตอนเคาน์เตอร์สำเร็จ (เฉพาะคนเล่น) fallback เป็น particle `END_ROD`
