# หุ่นไม้หยงชุน (`wooden_dummy`)

**สถานะ:** 🔨 เขียนโค้ดแล้ว (2026-10-19, P3; รอบสอง 2026-11-02, D66) ยังไม่ได้ทดสอบในเกม ภาพและเสียงยังเป็นแบบชั่วคราว

## แนวคิด
หุ่นไม้ฝึกหยงชุน (มู่เหรินจวง) ที่ตั้งนิ่งและมีแขนไม้ยื่นออกมาหลายทิศ หุ่นจะ "ส่ง" ชุดท่ามาให้ ผู้เล่นต้องปัดป้องตามลำดับให้ครบก่อนหมดจังหวะ เหมือนเกม Audition ยิ่งฝึกนาน ชุดท่ายิ่งยาวและเร็วขึ้น เกมนี้ฝึกความจำระยะสั้นและความแม่นของนิ้ว

## รูปแบบ
- **ประเภท:** Station
- **หน้าตาบล็อก (D66, D68, D71):** หุ่นไม้หยงชุนสูง 2 บล็อก (`HALF` lower/upper แบบประตู ต้องมีที่ว่างด้านบนถึงวางได้) โมเดลจาก Blockbench ของผู้ใช้ (ต้นฉบับ `docs/textures/wooden_dummy.bbmodel`): เสา หมวกบนยอด และแขน 12 แขนเป็นคู่หมุนรอบเสาหลายมุมหลายระดับ บล็อกล่างวาดส่วนที่ต่ำกว่า y 16 บล็อกบนวาดที่เหลือ หันหน้าเข้าหาคนวางทีละ 22.5° (`rotation` 0–15 แบบป้าย)
- **ปุ่ม:** WASD = ขึ้น / ซ้าย / ลง / ขวา, `SPACE` = ท่าปิดชุด
- **Input profile:** `keys=[UP, LEFT, DOWN, RIGHT, SPACE]`, `camera=FREE_LOOK` (ตัวหันเข้าหาหุ่นและล็อก เมาส์หมุนกล้องได้อิสระ, D66), `crosshair=false`, `sendIdlePresses=false`
- **Channel:** `WORLD_ARROW`
- **ค่าเริ่มต้น:** ไม่มี HP (เล่นไปเรื่อยๆ จนพลาด, D40), จบเมื่อโดนฟาดครั้งแรก (`MaxMistakes` ไม่มีผล, D77)
- **ท่าทางที่คนภายนอกเห็น:** `WING_CHUN` (ยืนหน้าหุ่น ปัดแขนสลับซ้ายขวาเป็นจังหวะแบบ loop)
- **คำใบ้ตอนเริ่ม:** "หุ่นจะส่งกระบวนท่ามา… รับให้ครบตามลำดับ"

## Pattern
หนึ่ง cue = หนึ่ง **ชุดท่า** (`SEQUENCE`) ของลูกศร ↑ ← ↓ →
- หุ่นแสดงชุดท่าทั้งชุดพร้อมกัน แล้วเวลาของชุดเริ่มนับ
- ผู้เล่นกดตามลำดับ กดถูกหนึ่งปุ่ม ลูกศรนั้นสว่างเป็นสีทอง
- **กดผิด (เปลี่ยน 2026-10-21, D39):** หุ่นฟาดเข้าให้ (knockback + damage 5 จริง + หิว 1 น่อง, D80) และ **session จบทันที** (FAIL) ต้องคลิกหุ่นใหม่เพื่อเริ่มอีกครั้ง (เดิม: ชุดเริ่มใหม่ตั้งแต่ลูกศรแรก)
- **กดครบก่อนหมดเวลา:** ชุดพร้อมปิด แล้วเข้าสู่ **ท่าปิดชุด** (ด้านล่าง)
- **หมดเวลาก่อนกดครบ (D77):** โดนฟาดและ session จบทันทีเหมือนกดผิด (เดิม: mistake + บทลงโทษเล็ก แล้วไปชุดถัดไป)

### ท่าปิดชุด (`SPACE` แบบ Audition, ตัดสินแล้ว 2026-10-19)
ทุกชุดมี **จุดส่งแรง** อยู่ที่ประมาณ 85% ของเวลาชุด หุ่นแสดงเป็นจังหวะที่วิ่งเข้าหาจุดนั้น (diegetic: ประกายวิ่งไปตามเส้นหมึกใต้แถวลูกศร)
- ผู้เล่นต้องกดลูกศรให้ครบก่อนถึงจุดส่งแรง แล้วกด `SPACE` ให้ตรงจุด
- **ระดับการปิด:**

| ผล | กรอบเวลารอบจุดส่งแรง | แต้ม (D40) | นับว่า |
| :--- | :--- | :--- | :--- |
| `PERFECT` | ±2 tick | 2 | ผ่าน |
| `GOOD` | ±5 tick | 1 | ผ่าน |
| กดเร็ว/ช้าเกิน หรือไม่กด | นอก ±5 tick | 1 | ผ่าน (แต่ไม่ได้โบนัส) |
| กด `SPACE` ตอนลูกศรยังไม่ครบ | — | — | **โดนฟาดออก** เหมือนกดผิด (D39) |

- กดลูกศรครบหลังเลยจุดส่งแรงแล้ว (แต่ยังไม่หมดเวลา) = ผ่านแบบไม่มีท่าปิด (HP −1)
- ท่าปิดไม่ใช่ข้อบังคับ ผู้เล่นใหม่ผ่านได้ด้วยลูกศรอย่างเดียว ส่วนคนเก่งใช้ `PERFECT` ขึ้นด่านเร็วขึ้น
- **ลูกศรกลับทิศ** (สีแดง, ตั้งแต่ด่าน 3): ต้องกด **ทิศตรงข้าม** แทน (แบบ Audition ระดับสูง)

### โหมดไม่รู้จบและด่าน (D40, 2026-10-21)
เล่นต่อไปเรื่อยๆ จนกว่าจะพลาด ไม่มี HP และไม่มีการชนะ
- **แต้ม:** ผ่านชุด = 1 แต้ม, ปิดชุดแบบ `PERFECT` = 2 แต้ม ทุก **3 แต้มขึ้นด่าน**
- **ขึ้นด่าน:** เลขด่านขึ้นตัวใหญ่ด้านบนจอ ("ด่าน 4") ค้างประมาณ 2.5 วินาที พร้อมเสียงระฆังเบาๆ (เฉพาะคนเล่น) ด่าน 1 ขึ้นตอนเริ่มชุดแรก
- **particle ขึ้นด่าน (D66, D67, ทุกคนรอบหุ่นเห็น ไม่เกิน 48 บล็อก):** ด่าน n มีวงแสง n วงรอบเสา (สูงสุด 10 วงเต็มเสา) ขึ้นจากโคนทีละวงทุก 2 tick วงล่าสุดใหญ่และมีประกาย `END_ROD` สีตามช่วงด่าน 1–5 ขาว, 6–10 หยก, 11–15 ทอง, 16+ แดง ด่านธรรมดาจบด้วยประกายเล็กบนยอด **ทุก 5 ด่าน** เป็นฉากพิเศษที่ใหญ่ขึ้นทุกครั้ง (สูงสุดที่ด่าน 20): คลื่นควันแผ่บนพื้น, เสาแสงพุ่งจากยอด, น้ำพุประกาย `TOTEM_OF_UNDYING` (ด่าน 15+ เป็น `FIREWORK`), ด่าน 10+ มีแสงวาบ (`DummyFx.STAGE_UP`, `client/render/station/wooden_dummy/DummyEffects`)
- **ความยากต่อด่าน** (ตัวเลขเริ่มต้น จูนตอนทดสอบ):

| ค่า | สูตร | Difficulty 1 / 2 / 3 |
| :--- | :--- | :--- |
| ความยาวชุด | เริ่มต้น + (ด่าน − 1) สูงสุด 12 | เริ่ม 3 / 4 / 4 |
| เวลาต่อลูกศร | เริ่มต้น − (ด่าน − 1) ไม่ต่ำกว่าขั้นต่ำ | เริ่ม 15 / 12 / 10 tick, ขั้นต่ำ 6 / 5 / 4 tick |
| เวลาต่อชุด | 16 tick (อ่าน) + ความยาว × เวลาต่อลูกศร | ด่าน 1 = 61 / 64 / 56 tick |
| ลูกศรกลับทิศ | ตั้งแต่ด่าน 3 สุ่ม 0 ถึง min(ด่าน − 2, ความยาว ÷ 3) | |

- **ผลลัพธ์:** ข้อความจบบอกด่านที่ไปถึง ("แขนหุ่นฟาดเข้าให้ ไปได้ถึงด่าน 7") และบันทึกด่านสูงสุดของแต่ละคนใน scoreboard `bhg_dummy_stage` (เก็บค่าสูงสุด) ใน stats ทั่วไปนับเป็น `FAIL`
- ของรางวัล: drop เฉพาะเมื่อ admin ตั้ง loot table แต่โหมดนี้ไม่มีการชนะ จึงยังไม่มีทาง drop (ไอเดีย: loot ตามด่าน ดูคำถามเปิด)

## บทลงโทษ
- **จบรอบ (กดผิด, กด `SPACE` ก่อนครบ, หรือหมดเวลา, D77):** knockback + damage 5 ไม่สนเกราะ + หิวลด 2 แต้ม (1 น่อง) (D39, D40, D80) ไม่มี Slowness เพราะการจบเป็นเรื่องปกติของโหมดไม่รู้จบ
- **เอฟเฟคกระแทกตอนแพ้ (D77, ทุกคนรอบข้างเห็นและได้ยิน):** ระเบิดเล็ก ประกาย crit และรอยฟันตรงจุดที่แขนหุ่นโดนตัว ฝุ่นฟุ้งที่เท้า เสียงไม้กระแทกกับเสียง knockback แล้วผู้เล่นจึงกระเด็น
- **ทุบตรงๆ:** หุ่นไม่พัง (`BruteForce=KEEP`) แต่ดีดกลับ: knockback + damage 2

## การแสดงผล
- **คนเล่นเห็น (บนจอ, D39):** เดิมแถวลูกศรลอยอยู่หน้าหุ่นในโลก แต่ทดสอบแล้วโดนหุ่นบังจนมองไม่ครบ จึงย้ายมาวาดบนจอ (HUD) ใต้กลางจอ
  - แถวลูกศรบนแผ่นพื้นโปร่งแสง ลูกศรถัดไปที่ต้องกดใหญ่กว่า ลูกศรที่ผ่านแล้วเป็นสีทอง ลูกศรกลับทิศเป็นสีแดง
  - แถบเวลาใต้แถวลูกศรค่อยๆ หดลง ขีดบนแถบคือจุดส่งแรง เมื่อกดลูกศรครบจะขึ้นคำว่า Space ใต้ขีด
  - กดผิด: แถวทั้งแถวเป็นสีแดงเข้มและสั่น แล้ว session จบ
  - (P6) แขนหุ่นที่ตรงกับลูกศรปัจจุบันเรืองแสงจางๆ, ผ่านชุดหุ่นสั่นเบาๆ พร้อมเสียงไม้กระทบเป็นชุด
- **HUD:** แถวลูกศร + แถบเวลา (ข้างบน) ไม่มีคำใบ้ปุ่มแยก
- **เสียง:** เสียงไม้กระทบเบาๆ ทุกครั้งที่กดถูก, เสียงชุดกระทบตอนผ่านชุด, เสียงไม้ฟาดตอนหมดเวลา (เฉพาะคนเล่น) **เสียงหมัด** คนรอบข้างได้ยินด้วย (D66): server เล่นเสียง vanilla ที่จุดหมัด ยกเว้นคนต่อยที่ได้ยินจากเครื่องตัวเอง ไม่เกิน 1 ครั้งต่อ 3 tick
- **Epic Fight (D66):** เริ่มเล่นแล้วเข้าโหมดต่อสู้ของ Epic Fight อัตโนมัติ สลับโหมดไม่ได้ระหว่างเล่น จบแล้วคืนโหมด vanilla ถ้าเดิมอยู่โหมดนั้น
- **ตำแหน่ง (D42):** คลิกขวาแล้วถูกย้ายไปยืนห่างหุ่น 1.3 บล็อกในด้านที่ใกล้ที่สุดจาก 4 ด้าน (ด้านที่ว่างและมีพื้น) หันหน้าเข้าหุ่น
- **หมัด (D41, D42):** กดลูกศรถูก = หมัด Epic Fight สลับซ้ายขวา + ประกายและเสียงหมัดกระทบตรงจุดตามทิศลูกศร (W บน, S ล่าง, A ซ้าย, D ขวา) ท่าปิดชุด = หมัดหนัก + ระเบิดใหญ่ คนเล่นเห็นทันทีที่กด
- **คนภายนอกเห็น:** หุ่นตั้งนิ่ง (หุ่นหยงชุนของจริงก็ตั้งนิ่ง จึงดูเป็นธรรมชาติ) กับผู้เล่นที่ปัดแขนซ้อมอยู่หน้าหุ่น ตอนหมดเวลาเห็นผู้เล่นโดนดีดถอยเล็กน้อย
- **bhfx / fallback:** screen shake เบาๆ ตอนโดนฟาด (เฉพาะคนเล่น) fallback เป็นไม่มี

## ความสัมพันธ์กับเกมอื่น
`tangled_root` ใช้ลูกศรตามลำดับเหมือนกัน ถ้าทำทั้งคู่จะซ้ำกัน ต้องออกแบบหญ้าพันรากใหม่ก่อนทำ (ดู [`tangled_root.md`](tangled_root.md))

## คำถามที่ยังเปิดอยู่
- ตำแหน่งจุดส่งแรง (85%) และกรอบ ±2/±5 tick ต้องจูนตอนทดสอบ
- ท่าปิดแบบ `PERFECT` ควรมีเสียงหรือภาพพิเศษ (เช่น หุ่นสะเทือนแรงกว่าปกติ) เฉพาะคนเล่น
