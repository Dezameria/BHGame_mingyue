# bhgame 0.2.2

รวมอัปเดตตั้งแต่ 0.1.21 ถึง 0.2.2 (2026-11-03 – 2026-11-05)

## 🧍 หุ่นฝึก `sparring_dummy` (ใหม่)

### ตัวหุ่น
- mob ระบบ Epic Fight วนเดินไล่ → ตีด้วยท่าที่ตั้งไว้ → พัก
- เกิดจากไข่ spawn
- ตั้งชื่อได้ ใช้โค้ดสี `&` ได้ เลือกให้ชื่อแสดง Always หรือ On look
- ถ้าเป้าหมายเลือดต่ำกว่า % ที่ตั้งไว้ หุ่นจะหยุดตีจนเป้าหมายเลือดเต็ม
- สั่งให้หุ่นสองตัวตีกันเองได้

### ไม้สั่งหุ่น `sparring_baton`
- คลิกขวาที่หุ่น → เปิดหน้าตั้งค่า
- `Shift` + คลิกขวาหุ่นสองตัว → สั่งให้ตีกัน

### หน้าตั้งค่า (ภาษาอังกฤษ 4 แท็บ)
หัวหน้าแสดงชื่อหุ่น

| แท็บ | ตั้งค่าอะไรได้ |
|---|---|
| **Moves** | รายการท่า, ค้นหาท่าของ Epic Fight, ความเร็วแยกแต่ละท่า, pattern ตามเงื่อนไข 6 แบบ (สูงสุด 8 ชุด) |
| **Behaviour** | การไล่เป้าหมาย (Stay / Walk / Run / Auto), ช่วงพัก, ระยะ, Stop below |
| **Stats & Gear** | เลือด, ความเร็ว, อุปกรณ์ (คัดลอกจากกระเป๋า), ชื่อ |
| **Commands** | รันคำสั่งตาม event `engage` / `target_low` / `move` / `hurt` / `death` |

### คำสั่ง
```
/bhgame sparring <หุ่น> info|moves|order|pause|range|chase|target|speed|stopbelow|command|name
```

### สิทธิ์ (config)
- `sparring.batonPermissionLevel` = 2
- `sparring.commandPermissionLevel` = 2

### ประสิทธิภาพ
- หุ่นที่กำลังตีใช้ราว 11 µs ต่อตัวต่อ tick ถ้ามี 400 ตัวจะเพิ่มราว 9% ของ tick
- หุ่นที่ยืนเฉยใช้ราว 3 µs ต่อตัว (ถูกกว่า iron golem)

## 🔮 แท่นประชันปราณ `qi_station`

| ปุ่ม | ผล |
|---|---|
| คลิกขวา | ส่งคลื่น |
| `Shift` + คลิกขวา | คลื่นหลอก (อีกฝ่ายโดนหลอกเสียแรง 0.15) |
| ค้าง `Shift` | ดึงลูกแก้วกลับ |

- ถ้าดึงตอนอีกฝ่ายดัน แรงจะย้อนไปหาคนดัน
- ถ้าดึงทั้งคู่ แรงจะหักล้างกัน
- ระหว่างดึงจะสะท้อนคลื่นไม่ได้
- ตอนดึงมี particle ปราณฟ้าและเสียง
- กด F5 แล้วหมุนกล้องได้

## 🥋 หุ่นไม้ `wooden_dummy`
- หันได้ 16 ทิศตามคนวาง และโมเดลไม่ขึ้นสีดำแล้ว
- ถ้าตอบไม่ทันเวลา ผู้เล่นจะกระเด็นแล้วแพ้ทันทีเหมือนกดผิด มี particle และเสียงกระแทก
