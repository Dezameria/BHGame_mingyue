## 🧍 ใหม่! หุ่นฝึกต่อสู้
หุ่นที่ออกท่าตีใส่จริงด้วยระบบ Epic Fight ไว้ซ้อมรับ ซ้อมหลบ หรือจัดฉากประลองในโรล
- ตั้งท่าโจมตี ความเร็ว ระยะ และจังหวะพักได้เอง
- ตั้งเงื่อนไขเปลี่ยนท่าได้ เช่น โดนตีแล้วสวนกลับ
- หยุดตีเองเมื่อคู่ซ้อมเลือดเหลือน้อย ไม่ต้องกลัวตาย
- ใส่อาวุธ/ชุด และปรับเลือดหรือความเร็วได้
- ตั้งชื่อหุ่นได้ ใช้สี `&` ได้ด้วย
- สั่งให้หุ่นสองตัวประลองกันเองได้
-# 🔧 ตั้งค่าด้วย **ไม้สั่งหุ่น** (คลิกขวาที่หุ่น) หรือคำสั่ง `/bhgame sparring` สำหรับผู้ดูแล

## 🔮 แท่นประชันปราณ
เพิ่มท่าใหม่ **ค้าง `Shift` เพื่อดึงลูกแก้วกลับ**
- ดึงจังหวะที่อีกฝ่ายกำลังดัน → แรงจะย้อนกลับไปหาเขา
- ถ้าดึงพร้อมกันทั้งคู่ → แรงหักล้างกัน
- แต่ระหว่างดึงจะสะท้อนคลื่นไม่ได้ ต้องเลือกจังหวะดีๆ
- คลื่นหลอกยังเป็น `Shift` + คลิกขวา และตอนนี้ถ้าโดนหลอกจะเสียแรงมากขึ้น
